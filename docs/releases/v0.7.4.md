## Producer Studio 0.7.4 for Windows

**Download:** `Producer-Studio-Setup-0.7.4.exe` below (about 850 MB). Per-user install, no admin rights needed. The installer isn't code-signed yet, so Windows SmartScreen may warn on first run: choose **More info → Run anyway**. Installing over 0.7.3 or earlier keeps your projects, settings and voices.

The app doesn't tell you about new versions yet (that waits for signed builds), so if you have 0.7.3, download and install this one yourself.

### What's new since 0.7.3

**VoiceStudio 0.5.8**
- Voice Studio now runs VoiceStudio 0.5.8 (it was 0.5.6). After installing, open **Voice Studio → Engine** and choose **Update**: it downloads the new engine once (several GB, faster than the first install).
- **Model licences.** VoiceStudio now uses a model whose licence doesn't allow commercial use only after you accept its terms on this computer. That includes OmniVoice, the default voice engine. The Engine tab lists those models with **Review & accept**, and anything refused for one opens the same dialog. A voiceover asked for on the website waits for this too, and says so.

**Sound effects from a description**
- **Voice Studio → Audio tools → Sound effects**: describe a sound ("rain on a tin roof with distant thunder"), pick 1–30 seconds, and add it to the library. It uses MOSS-SoundEffect (Apache-2.0), installed with one click, and needs an NVIDIA graphics card.
- While this computer is on with sound effects installed, you can make them from **producerstudio.app** too (Voice Studio → Audio tools there): this computer makes them and they land in the space's library.

**A voice changer that keeps your delivery**
- **Audio tools → Voice changer**: a recording, or a video (MP4, MOV, M4V, MKV), in one of your voices. **Keep my delivery** changes only the voice, so the timing, rhythm and intonation stay and lip-sync survives; a video comes back with its picture. It needs CosyVoice 3 from the Engine tab.

**How a line is said**
- **Text to speech**: with one of your voices, **How it's said** ("warm and excited", "a calm whisper") goes with the script. IndexTTS2 takes it as its emotion, CosyVoice 3 and VoxCPM2 as a direction; other engines read the script plainly. It works from the website through this computer too.
- **Stories**: `[emotion: excited]` after a character's name, or the box under each line, says how that line is said.

**From producerstudio.app, also in this build**
- Flowing scenes and long shots for AI clips in Producer (live on the website since 24 Nov).
